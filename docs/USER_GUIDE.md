# Using the workstation

1. **Choose an element.** Click its cell, enter an exact symbol/name/Z in Search, or focus the table and use arrow keys. The two detached rows are the lanthanides and actinides. Color the cells by block or by category. In a narrow window use **Controls** and **Analysis** to open the side panels.
2. **Establish the physical system.** The inspector's configuration and first IE always describe the **neutral reference atom**. In single-orbital mode, selecting “exact O7+ ion”, for example, changes the physical system to one electron bound to a charge-8 nucleus. It does not solve for neutral oxygen. Returning to full-atom mode restores the neutral model.
3. **Explore an orbital.** Choose an occupied subshell or set n, l and the angular state. Turn off “Allow unoccupied” to restrict choices. In a real basis the sign colors distinguish lobes of opposite sign, not positive/negative charge. In a complex basis hue follows arg ψ. The angular index in a real tesseral combination labels a combination of ±m, not a definite magnetic projection. For a stationary real state and for m=0 the probability current is zero.
4. **Explore all electrons.** Choose Full-atom density. H defaults to its analytic 1s density; He–Ar default to imported HF. Model Σ uses spherical averages for the occupied shells. Layer visibility and opacity are display-only, independent of physical occupancy. HF is one total-density layer: the absence of orbital phase, current and subshell sliders is intentional. For Z>18 no bundled HF dataset exists.
5. **Inspect spatial structure.** Drag to orbit, right-drag to pan, scroll to zoom. Reset camera to refit. Points are samples, not individual electrons. XY clips by z, XZ by y, YZ by x. The offset and slab thickness are in pm in the same world coordinates as the cloud. Framing radius is not a screen ruler. HF framing encloses about 99.9% of tabulated electrons; zooming does not rescale the physics. The nucleus marker is not to scale.
6. **Read the panels.** In single mode P(r) is per pm, integrates to one and includes the radial Jacobian. Dashed markers show radial nodes; the cyan marker is the mean radius. In full mode the plot is the radial **electron count** in e/pm; its integral is compared to Z, even if some layers are hidden. The Levels tab distinguishes a one-electron energy, a screening estimate, the neutral first IE (shown at −IE for comparison), and an HF *total* energy. A tabulated HF number is not an experimental binding energy.
7. **Check the evidence.** The inspector distinguishes the displayed model from the preferred neutral total-density provider. Hover field labels for sources/uncertainty, or inspect the normalized data offline. Superheavy configurations are predictions. No high-accuracy heavy-element wavefunction is hidden behind the fallback.

The initial view can be shared with query parameters, for example `/?z=8&mode=atom&samples=75000`. `adaptive=0` keeps point counts fixed for benchmarking. This is not a full session export. Without WebGL2 use the analytical panels; without a worker result the telemetry is not a measured density integral.
